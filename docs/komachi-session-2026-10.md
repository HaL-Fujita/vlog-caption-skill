## 保存と再開

- `/workspace/komachi-video-03/edit-status.json` が最新の日本語・派生版、保存先、検証結果を指す。
- `/workspace/komachi-video-03/fixed-v5` に位置固定版の編集計画・描画スクリプト・検証記録がある。
- 字幕なしのカット映像と音声ミックスは同じ作業ルートの `timing-v4`。言語や名札の変更は、この映像から字幕を再合成して二重の焼き付けを避ける。
- 日本語の完成品フォルダは `小町_TikTok_03_ケーティ位置固定版`。過去の版を上書きせず、派生版には別フォルダ・別名を使う。
- 1〜3本目の素材、BGM、ロゴ、編集設定、過去の書き出しは、対応する作業フォルダに残す。保存を求められた時点でリポジトリ外へアーカイブし、ファイルごとの SHA-256 と照合する。
- リポジトリへは再利用できる作業メモのみ保存する。私的な動画、音声、文字起こし、個別の共有 URL を Git に入れない。
- 字幕だけの修正では完成品の AAC をコピーし、圧縮音声とデコード音声のハッシュ一致を確認する。
- Filebin は承認済みの受け渡し方法だが一時保存。バックアップの恒久保存先として扱わない。納品後はサイズと全データの SHA-256 を照合し、期限を案内する。

今回の環境では音声の直接試聴はできない。音声認識・発話区間・音量・サンプル照合による確認を、試聴済みとは表現しない。
